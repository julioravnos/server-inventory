# server-inventory
Um script de inventário para servidores windows trazendo informações completas incluindo do Hyper-V e Maquinas virtualizadas

Este script foi desenvolvido para inventário de Servidores Windows Server e inventário de maquinas virtualizadas em Hyper-V.
Muitas vezes precisamos criar maquinas virtuais em servidores e devido a correria acabamos esquecendo de documentar (o que é muito comum quando se trabalha em, ambientes críticos como eu), desta forma optei em criar um script em PowerShell para que fosse criado um relatório em HTML e PDF com exportação dos dados coletados em CSV para poder criar posteriormente a documentação de ativos.

Este script funciona perfeitamente para mim e pode ser adaptado a suas necessidades conforme desejar desde que mantendo os créditos da fonte original.

-------------------------------------------

An inventory script for Windows servers that provides comprehensive information, including details on Hyper-V and virtualized machines.

This script was developed to inventory Windows Servers and the virtual machines running on Hyper-V. In the fast-paced environments where I work—which are often mission-critical—it is all too easy to forget to document the creation of new virtual machines. To address this, I created a PowerShell script that generates reports in HTML and PDF formats, while also exporting the collected data to a CSV file, which can then be used to build an asset inventory.

This script works perfectly for my needs, and you are welcome to adapt it to suit your own requirements—provided that you retain the original source credits.
